# Sudoku Paralelo

Projeto da disciplina de Processamento Paralelo e Distribuído.

## Objetivo
Ler vários Sudokus 9x9 de arquivos estruturados, resolver cada um com
backtracking + MRV e distribuir a resolução entre múltiplos processos,
comparando a execução sequencial com a paralela (tempo, speedup, eficiência).

## Formato de entrada
- 9 linhas de 9 dígitos por tabuleiro; `0` = célula vazia
- Tabuleiros separados por linhas em branco
- Linhas iniciadas por `#` são comentários
